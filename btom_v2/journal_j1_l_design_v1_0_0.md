# Journal J1-L publication-grade pre-execution package v1.0.0

This compact package operationalizes, without changing, the scientific and analysis freezes at `journal-j1-v0.7.0` and `journal-j1-v0.7.1`. It asks whether a non-operative discrepancy in the represented state of a separate operator continues to increase communication when action labels are opaque. ICAART remains frozen.

## Frozen design

The bank contains 54 variants: six archetypes by three difficulty levels by three variants. Every variant has a focal agent, addressed partner, and separate operator. The partner's immediate-assignment proposition **q** is represented accurately (`M_R=0`). Only the independent operator proposition **r** changes. Its branch shares no actionable resource, target, destination, route, prerequisite, tool, hazard, object, objective, or dependency with q. Messages reach only the partner, cannot be relayed, and cannot change the operator's assignment; the episode ends after immediate assignments. Both propositions have the same family, template, value format, alternative cardinality, terminal status, and depth (1 for direct/distractor, 2 for compositional). Distractor variants contain exactly one static fact.

The four conditions are C0 (CUED, `M_I=0`), C1 (CUED, `M_I=1`), N0 (NEUTRAL, `M_I=0`), and N1 (NEUTRAL, `M_I=1`). Cued labels are `SEND_CORRECTION` / `CONTINUE_TASK`; neutral labels are `ACTION_A` / `ACTION_B`, with a per-variant mapping. Across interfaces only labels change; within an interface only r's recorded value changes.

## Analysis and operational freeze

The primary estimand is `mean(Y_N1-Y_N0)`. Persistence requires both the one-sided exact paired McNemar/binomial discordance p-value at most .05 and an effect at least .25. The key secondary estimands and 100,000-resample type-7 percentile bootstrap remain exactly those in v0.7.1 (literal `journal-j1-lexical-ablation-bootstrap-v0.7.1`, integer seed 1202210195).

The deterministic builder verifies the seven parent hashes, constructs balanced nuisances and a four-round schedule, renders 216 prompts, and uses the official complete-conversation GPT-OSS Harmony renderer. Execution readiness fails closed unless all 54 C0/C1 and all 54 N0/N1 token-count pairs match. Generated banks, prompts, schedules, and audits exist only in the Actions artifact. No behavioral call is part of this package.
